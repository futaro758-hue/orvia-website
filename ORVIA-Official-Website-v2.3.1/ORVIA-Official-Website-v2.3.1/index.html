ORVIA

ORVIAは、「自由に遊ぶ。仲間を尊重する。ゲームを楽しむ。」を理念に活動するゲーミングチームです。

APEX Legendsを中心に、競技活動やカスタム大会、イベント運営を通して、プレイヤー同士が成長できる環境を目指しています。

勝敗だけでなく、挑戦すること、仲間を思いやること、ゲームを楽しむことを大切にし、一人ひとりが自分らしく輝ける場所を創っています。
